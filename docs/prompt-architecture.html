Jove Prompt Architecture

How the system prompt is assembled. Tier 2 varies by persona mode — the rest is shared.

Persona modes:
Identical across all modes
Same structure, content varies
Unique to specific mode(s)
Conditional on conversation state

Tier 1 — Constitutional

Seven immutable rules. Never changes regardless of mode.

Constitutional Rules (7)
Not a therapist. User is the author. Mirror exact language. One question per turn. Nothing enters manual without confirmation. No clinical framework names. Direct when asked what Jove is.
ALL

Tier 2 — Voice & Behavior

One block per section. Selected mode(s) determine content.

AuDHD: "both autistic and ADHD… two systems that pull in opposite directions"

#13 masking (aut/audhd) · no-journaling (dys) · performing (gen)

Landing Examples (6)
Same structure (6 labeled examples). Different situations per mode.
Autistic: internal escalation, absorbing stress, masking, flat delivery, pattern repetition
AuDHD: exec function collapse, interest-based motivation, structure-novelty tension, burnout cycle
Dyslexic: seeing the whole picture, workaround nobody sees, speed mismatch
General: absorbing stress, performing, pattern repetition (neurotype-neutral versions)

Tier 3 — Conversation Mechanics

Assembled at call time from conversation flags. Same for all modes.

First Message
When: first turn of a new session. Sets the opening frame.
ALL
Returning User

ALL
Approaching Checkpoint
When: enough material gathered. Prompts Jove to propose a Manual entry.
ALL
Checkpoint Just Returned
When: user just confirmed/rejected an entry. Brief acknowledgement, return to conversation.
ALL
Readiness Gate

ALL
Clinical Material

ALL

First-Session Wrapper
