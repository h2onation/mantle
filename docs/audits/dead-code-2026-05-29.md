# Dead-code audit — 2026-05-29

Branch: `dead-code-audit`. **Read-only audit — nothing was deleted.** This is a decision document.

## Method

Multi-angle sweep (ts-prune + knip + env-var diff + the `docs/rules.md` Dead Features list) → **adversarial per-candidate verification** (one verifier per candidate, full-repo grep incl. dynamic/string/test/config refs, conservative bias) → **skeptic refute-pass on every safe-to-delete candidate** → **completeness critic** for what the seed tools structurally miss. 115 agents, 90 candidates adjudicated + 6 critic finds. The true deletions, the orphan routes, and the env facts below were then independently re-verified by hand.

**Headline:** almost nothing flagged is *dead code*. The overwhelming majority are **live symbols carrying a redundant `export` keyword** ("used in module" — the symbol is consumed inside its own file, just never imported elsewhere). Deleting those symbols would break the build; only the `export` modifier is removable, and that is a zero-behavior, `tsc`-checked, optional cleanup. The genuinely-removable code is a much shorter list, below.

| Safe — trivial `export`-keyword removal only (no behavior change) | ~39 |
