Checkpoint card · Manual Plate vocabulary

The checkpoint card now mirrors the Manual page's Plate + tab pip exactly. Tab pip is the same solid walnut chip (rgb(135, 90, 55)) used in every layer of the Manual, not a transparent gradient. Plate body uses --session-walnut-surface and --session-plate-shadow. The shipping component can reuse <LayerHeader /> as-is.

What's exactly the Manual page
  • Tab pip: solid rgb(135, 90, 55) walnut chip, cream-on-walnut text, Spectral 18px / 500 / -0.01em, padding 8px 18px, radius 8, the same 0 2px 6px / inset 0 1px 0 shadow. Sits on the top edge with translateY(-50%).
  • Plate body: --session-walnut-surface, --session-bubble-border, --session-plate-shadow, radius 18, padding 26px 14px 22px, backdrop-filter blur(28px) saturate(140%).
  • Same 18px left inset for the pip — so it sits in the same spot a Manual layer's pip does, on the same x-axis.
What's checkpoint-specific
  • Body holds a single italic title at 21px instead of a list of entries — this is one proposal, not a section.
  • Small mono caps eyebrow POTENTIAL MANUAL ENTRY in walnut-meta-strong at the top of the body — the only verbal signal this isn't filed yet.
  • Warm halo glow underneath the whole frame. Manual cards don't carry this — it's what tells the eye "this is the moment to act."
  • Hairline above an inline "Tap to review" with a walnut chevron — the affordance Manual entries don't need.
  • No <i> info chip (the right-side circle in the Manual). The user already knows what they're looking at.
