Chat & color directions

Five re-palettes of the approved Kernel demo. Everything but the color and the chat is identical — same layout, same checkpoint, same Manual, same content, same fonts — so the only variable is palette and how the conversation feels. Each has the Desktop/Phone toggle and the live Add to Manual flow.

← the current base (1e · Kernel · Refined II)
Hearthwarm dark The dark-mode answer the app needs. Warm espresso-aubergine ground, candlelight amber, full-strength cream ink. Jove speaks from a lamplit vessel; the user from an ember one; the checkpoint glows like paper held to a flame. Oat & Inkbright · high-contrast The brightest, most modern-editorial option. Warm oat-bone paper, near-black ink, one persimmon accent. Flat crisp bubbles with confident borders — no glass. Calm, low-clutter, maximum legibility. Sage Grovegreen-forward Pushes the green. Jove fully owns a eucalyptus identity; the user answers in warm terracotta — the two voices read as green vs clay. Soft organic bubbles, green-gold morning light. Botanical, grown-up, warm. Rose Walnutwarm rosé An unexpected warm rosé — intimate and distinctive without being saccharine. Blush-linen ground, dusty-rose user glass against cooler cream Jove paper, walnut thread, muted-plum checkpoint. A romance-of-the-self palette. Slate & Brasscool · refined The only cool-ground option: greige-stone paper with an aged-brass accent used like a metal detail. Squarer architectural bubbles, hairline apparatus. The most luxury-editorial of the set — cool calm, one warm metal.

Built 2026-06-11 · each page's colophon (bottom strip) lists exact hexes. Mix-and-match reactions welcome — "Hearth for dark, Oat & Ink for light" is a valid answer, and so is "this palette, but the chat bubbles from that one."
